A selective early-flow paper trading bot for pump.fun bonding curves. It watches every new coin's first trades, enters once when the early flow is buy-dominated and the price has not already run away, and exits fast on take-profit, stop-loss, a trailing stop, or a 30-minute time stop.

## Run it

```sh
node main.ts
```
